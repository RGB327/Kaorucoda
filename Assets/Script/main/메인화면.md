# 씬 구성 가이드

## 계층

```
EventSystem

ScreenCanvas                         Canvas: Overlay, Sort Order 0
                                     Canvas Scaler: 1920x1080, Match Width Or Height, Match 1
                                     GraphicRaycaster
├── [ScreenManager]                  ← 스크립트
├── [UIRouter]                       ← 스크립트 (씬에 하나만)
└── ScreenRoot
    ├── MainMenuScreen               [MainMenuScreen]
    │   ├── StartButton
    │   ├── AchievementButton
    │   ├── SettingsButton
    │   └── QuitButton
    └── AchievementScreen            [AchievementScreen]
        ├── BackButton
        ├── SettingsButton
        └── ScrollView
            └── Viewport
                └── Content          Vertical Layout Group
                                     Content Size Fitter (Vertical: Preferred Size)

PopupCanvas                          Canvas: Overlay, Sort Order 100
                                     Canvas Scaler: ScreenCanvas 와 완전히 동일하게
                                     GraphicRaycaster
├── [PopupManager]                   ← DontDestroyOnLoad, 최초 씬에만 배치
└── PopupRoot                        RectTransform Stretch (전체)
    ├── Dimmer                       Image (검정, alpha 0.6), Stretch
    │                                Button → OnClick: PopupManager.OnDimmerClick
    ├── SettingsPopup                [SettingsPopup], 기본 비활성
    │   └── Panel                    중앙 앵커 + 고정 크기
    └── ConfirmPopup                 [ConfirmPopup], 기본 비활성
        └── Panel                    중앙 앵커 + 고정 크기
```

Dimmer 는 반드시 **PopupRoot 의 자식**이어야 한다. RefreshDimmer() 가
popupRoot.childCount 기준으로 형제 인덱스를 재배치하기 때문이다.

### 팝업은 프리팹이 아니라 씬 오브젝트다

화면(UIScreen)과 동일한 방식이다: `SettingsPopup`, `ConfirmPopup` 은 프리팹으로
Instantiate 하지 않고 **PopupRoot 아래에 미리 배치**해 두고, `PopupManager.Open()` /
`Close()` 가 `SetActive` 만 토글한다. 씬 시작 시 기본은 비활성 상태로 둔다
(Dimmer 처럼 `Awake`에서 강제로 꺼주진 않으므로, 에디터에서 직접 꺼둘 것).

각 팝업은 씬 전체에 인스턴스가 **하나뿐**이므로, `MainMenuScreen`과
`AchievementScreen`처럼 같은 팝업을 여러 화면에서 띄울 때는 두 스크립트의
필드에 **같은 PopupRoot 자식 오브젝트**를 그대로 드래그해서 연결한다.

### 여러 씬에서 재사용하기

`PopupManager`는 `Awake()`에서 `DontDestroyOnLoad`로 살아남는 싱글턴이다.
**PopupCanvas(와 그 아래 팝업들)는 가장 먼저 로드되는 씬(MainMenu 씬)에만 배치**하면 되고,
이후 `SceneManager.LoadScene`으로 다른 씬(Game 씬 등)으로 넘어가도
`PopupManager.Instance`와 그 자식 팝업들이 그대로 유지된다. 다른 씬에 실수로 또
PopupCanvas를 배치해도 `Awake`의 중복 체크가 새 인스턴스를 파괴하므로 안전하다.

새 씬에서 설정 팝업을 쓰려면:
1. 그 씬의 화면/버튼 스크립트에 `SettingsPopup` 필드를 하나 추가한다.
2. 인스펙터에서 그 필드에 (씬 전환 후에도 살아있는) `PopupCanvas/PopupRoot/SettingsPopup`
   오브젝트를 직접 드래그해서 연결한다. **주의:** 이 오브젝트는 새 씬을 열어도 하이러키에
   안 보일 수 있다 — DontDestroyOnLoad 오브젝트는 Play 모드에서만 하이러키에 나타나므로,
   에디터에서 연결하려면 MainMenu 씬을 열어 거기서 드래그해야 한다.
3. 버튼 OnClick 에서 `PopupManager.Instance.Open(settingsPopup)` 호출.
4. PopupCanvas 는 새로 만들 필요 없음 — 이미 살아있는 인스턴스를 그대로 쓴다.

씬을 직접 `SceneManager.LoadScene`으로 전환하는 코드(예: `MainMenuScreen.OnStartClick`)는
전환 직전에 `PopupManager.Instance?.CloseAll()`을 호출해 열려 있던 팝업을 정리한다.
(`ScreenManager.Push`를 통한 화면 전환은 이미 자동으로 처리된다.)

## 프리팹 (씬에 두는 것)

- `AchievementItem` — 목록 항목이라 개수가 가변적이므로 이것만 프리팹으로 Instantiate 한다.

팝업 루트는 Stretch(전체), 그 안의 Panel 은 중앙 앵커 + 고정 크기.
Panel 을 Stretch 로 두면 스케일 연출이 화면 전체를 대상으로 걸린다.

## 인스펙터 연결

| 컴포넌트 | 필드 | 값 |
|---|---|---|
| ScreenManager | rootScreen | MainMenuScreen |
| ScreenManager | allScreens | MainMenuScreen, AchievementScreen |
| PopupManager | popupRoot | PopupRoot |
| PopupManager | dimmer | Dimmer |
| MainMenuScreen | achievementScreen | AchievementScreen (씬 오브젝트) |
| MainMenuScreen | settingsPopup | SettingsPopup (PopupRoot 자식, 씬 오브젝트) |
| MainMenuScreen | confirmPopup | ConfirmPopup (PopupRoot 자식, 씬 오브젝트) |
| AchievementScreen | settingsPopup | SettingsPopup (MainMenuScreen 과 동일한 오브젝트) |

버튼 OnClick 은 각 화면 스크립트의 public 메서드로 연결한다.

## 동작 시나리오

| 상태 | ESC |
|---|---|
| 시작 메뉴 | 종료 확인 팝업 |
| 시작 메뉴 + 설정 | 설정 닫힘 |
| 업적 | 시작 메뉴로 |
| 업적 + 설정 | 설정 닫힘 → (또 누르면) 시작 메뉴로 |
| 시작 메뉴 + 종료 확인 | 확인 팝업 닫힘 |
